# 📝 To-Do List App

A minimal and stylish To-Do List web app built using **HTML**, **CSS**, and **JavaScript**.

This app lets users add, check off, and delete tasks — and keeps them saved using `localStorage`.

## ✨ Features

- ✅ Add new tasks
- 🗑️ Delete completed or unwanted tasks
- 🔄 Tasks persist even after refreshing (via `localStorage`)
- 📱 Responsive and clean UI

## 🚀 Getting Started

1. Clone the repo or download the ZIP  
2. Open `index.html` in your browser  
3. Start adding tasks!

## 💻 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- LocalStorage API
